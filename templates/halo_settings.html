Your IT administrator configures the connection on the AIrisk host, using the API and authorization URLs from Halo’s integration settings. Credentials stay on that host.

SettingValue to configure
HALO_API_URLHTTPS API base URL, including /api.
HALO_TOKEN_URLFull HTTPS OAuth token endpoint from Halo.
HALO_CLIENT_ID, HALO_CLIENT_SECRETDedicated client credentials with ticket read/write permissions.
HALO_TICKET_URL_TEMPLATEAgent ticket URL with {id} in place of the ticket number.
HALO_TICKET_TYPE_IDYour remediation ticket type ID.
HALO_TEAM, HALO_AGENT_IDOptional default team and Halo assignee. The AIrisk owner is recorded in the ticket description.
HALO_CUSTOMER_ID, HALO_SITE_ID, HALO_USER_ID, HALO_PRIORITY_IDRouting fields when required by your ticket type.
HALO_COMPLETED_STATUS_IDSComma-separated IDs that mean remediation was completed. Exclude cancelled or rejected statuses.
AIRISK_PUBLIC_URLOptional HTTPS address where your team accesses AIrisk.

Use “Create Halo ticket” on a saved action to send it. Schedule flask --app app halo-sync every five minutes to sync progress, or use “Sync Halo progress” on the action. The Windows package also provides AIrisk.exe halo-sync.

Ticket status, assignment, target date, and a recent public note are copied back. Private notes and attachments are not imported. Halo completion still needs the normal action evidence and independent verification.
