# Historical prototype reports

These PDFs, presentations and their generator scripts describe the pre-rebuild generic risk prototype. They are retained for traceability. They are **not evidence of the current application's security, architecture or completed remediation**, and some of their claims were contradicted by the runtime review.

Use the root README, ARCHITECTURE.md, docs/OPERATIONS.md and docs/REVIEW_AND_ROADMAP.md for the current product. The archived generators are not maintained application or release tooling.
